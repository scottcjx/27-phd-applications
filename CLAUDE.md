# PhD Applications Project

## Rules for Claude

1. Ask the user questions. Do not assume facts, choices, or preferences.
2. Write in simple English. Use ASD-STE100 rules when possible (skill: `writing-skills:asd-ste100`).
3. Make all visuals as web pages (HTML). Put the files in `visuals/`.
4. Record each action in `AUDIT_LOG.md`. Add one entry for each action.
5. Do not send personal data to external services without user approval.

## Folders

- `visuals/` : HTML pages (charts, trackers, timelines).
- `AUDIT_LOG.md` : log of all actions.
